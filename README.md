# delivery

Home of **Delivery Date Picker for WooCommerce** — a commercial WooCommerce extension that
lets customers choose exactly when their order is delivered, with a premium checkout calendar,
time slots, capacity limits, holidays and a SaaS-grade delivery schedule dashboard.

The plugin lives in [`delivery-date-picker/`](delivery-date-picker/).
